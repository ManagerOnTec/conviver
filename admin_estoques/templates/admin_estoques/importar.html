Importar Medicamentos a partir de planilha XLSX

Envie a planilha lista_medicamentos_completos.xlsx. O sistema irá identificar automaticamente:

  • Genérico — 1ª coluna (princípio ativo);
  • Comercial — 2ª coluna (produto de referência; se houver vários separados por “/”, cada um é cadastrado como produto);
  • Classe e Subclasse — 3ª e 4ª colunas;
  • Unidade de Medida e Via — 5ª e 6ª colunas.

Na próxima tela você poderá revisar cada linha e ajustar os dados antes de confirmar a importação.
